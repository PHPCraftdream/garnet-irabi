# Структура базы данных

> **Полная актуальная модель данных — в [data-model.md](data-model.md).**

Ранее этот файл дублировал часть описания схемы. Поддержание двух
параллельных документов (`database.md` + `data-model.md`) привело к
тому, что оба устарели в равной мере: неверные префиксы таблиц
(`ir_*` / `db_accounts` вместо фактического `db_ir_*`), несуществующие
колонки (`rating DECIMAL(3,2)`, `payments.amount INT + status ENUM`,
суффиксы `created_ut`) и ~28 неописанных таблиц. Поэтому содержательное
описание консолидировано в единственный источник — `data-model.md`, а
этот файл оставлен только как указатель.

Схема в `data-model.md` сгенерирована из **живой БД** (`SHOW TABLES` /
`SHOW CREATE TABLE`) и покрывает все 46 таблиц: имена колонок, типы,
NULL/DEFAULT, индексы, классификацию framework-vs-app и пометки о
связях/целостности. Если нужно свериться с актуальной структурой на
конкретном окружении — `php garnet sql "SHOW CREATE TABLE db_ir_<table>"`.
